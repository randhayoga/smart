# Portal SSO Integration Guide for Laravel Applications

This document provides a complete blueprint and specification for Antigravity (or any developer) to implement CodeIgniter Portal Single Sign-On (SSO) authentication in a new Laravel application.

---

## 1. Architectural Overview

The application integrates with an enterprise **CodeIgniter (CI) Portal** (e.g., Athena / RE Portal) where users log in once. The child application does not maintain its own passwords or local user accounts.

```
+--------------------------+
| Enterprise Portal (CI)   |
| User logs in here        |
+--------------------------+
             |
             | 1. Redirect to child app with session ID:
             |    https://new-app.domain/login?ciSession={SESSION_ID}
             v
+--------------------------------------------------------------------------------+
| Child Laravel Application                                                      |
|                                                                                |
|  [ GET /login ]                                                                |
|         │                                                                      |
|         ▼                                                                      |
|  AuthController::login()                                                       |
|    - If ciSession is missing -> Redirect to Portal URL                         |
|    - If ciSession exists     -> Call VerifySession Service                     |
|                                                                                |
|  VerifySession Service:                                                        |
|    1. Query Portal DB (RE_PORTALDB.dbo.ci_sessions) by ID                      |
|    2. Check session expiration against SESSION_LIFETIME                        |
|    3. Decode PHP session payload via session_decode()                          |
|    4. Extract employee NPK / username ($session['uname'])                      |
|    5. Query HRIS DB (USER_HRIS.dbo.hrd_employee) by employee_id                |
|    6. Return User model                                                        |
|                                                                                |
|  AuthController::login():                                                      |
|    - Call Auth::login($user) to establish Laravel session                      |
|    - Redirect to target dashboard/home page                                    |
+--------------------------------------------------------------------------------+
```

## 2. Prerequisites & Database Setup

### 2.1 Database Server & Drivers
* **Database Management System:** Microsoft SQL Server (`sqlsrv`).
* **PHP Extensions:** `php-sqlsrv`, `php-pdo_sqlsrv`, along with Microsoft ODBC Driver (msodbcsql17/18).

### 2.2 Shared Databases & Tables
The application needs read access to two central databases on the SQL Server instance:

1. **Portal Database (`RE_PORTALDB` or connection `portal`):**
   * **Table:** `dbo.ci_sessions`
   * **Key Columns:**
     * `id` (`VARCHAR`): CodeIgniter session ID.
     * `ip_address` (`VARCHAR`): Client IP.
     * `timestamp` (`INT` / `BIGINT`): Unix timestamp of the last activity.
     * `data` (`VARCHAR` / `VARBINARY`): Serialized PHP session string generated by CodeIgniter 3.

2. **HRIS Database (`USER_HRIS`):**
   * **Table:** `dbo.hrd_employee`
   * **Key Columns:**
     * `employee_id` (`VARCHAR`): Employee NPK / ID (Used as primary key).
     * `name` (`VARCHAR`): Full name.
     * `email` (`VARCHAR`): Email address.
     * `orgchart_id` (`INT`): Department ID.
     * `active` (`INT`): 1 for active employees.
   * **Table:** `dbo.hrd_orgchart` (optional, for department / organization info).

3. **Application Database:**
   * Your own application database for local tables, application entities, migrations, and session persistence (if `SESSION_DRIVER=database`).

## 3. Environment Variables (`.env`)

Add the following environment keys to `.env` and `.env.example`:

```dotenv
# Main Application DB Connection
DB_CONNECTION=sqlsrv
DB_HOST=127.0.0.1
DB_PORT=1433
DB_DATABASE=your_app_database
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

# External Databases on SQL Server
DB_DATABASE_PORTAL=RE_PORTALDB
DB_DATABASE_HRIS=USER_HRIS
DB_DATABASE_ATHENA=athena

# Session Lifetime (in minutes, should match Portal session lifetime)
SESSION_DRIVER=database
SESSION_LIFETIME=120

# Enterprise Portal URL
PORTAL_URL=http://localhost:8080/portal
APP_REDIRECT_URL=http://localhost:8080/portal
```

### 4.2 Application Configuration (`config/app.php`)

Ensure redirect URLs are exposed in `config/app.php`:

```php
'redirect' => [
    'portal' => env('PORTAL_URL', env('RE_PORTAL_URL', 'http://localhost:8080')),
],
'redirect_url' => env('APP_REDIRECT_URL', env('PORTAL_URL', env('RE_PORTAL_URL', 'http://localhost:8080'))),
```

### 4.3 Auth Configuration (`config/auth.php`)

Ensure the default guard is `web` and the user provider uses `App\Models\User`:

```php
'defaults' => [
    'guard' => env('AUTH_GUARD', 'web'),
    'passwords' => env('AUTH_PASSWORD_BROKER', 'users'),
],

'guards' => [
    'web' => [
        'driver' => 'session',
        'provider' => 'users',
    ],
],

'providers' => [
    'users' => [
        'driver' => 'eloquent',
        'model' => env('AUTH_MODEL', App\Models\User::class),
    ],
],
```

### 5.2 User Model (`app/Models/User.php`)

```php
<?php

namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, Notifiable;

    protected $connection = 'USER_HRIS';
    protected $table = 'USER_HRIS.dbo.hrd_employee';
    protected $primaryKey = 'employee_id';
    public $incrementing = false;
    protected $keyType = 'string';
    public $timestamps = false;

    protected $fillable = [];

    protected $hidden = [
        'password',
        'remember_token',
    ];

    /**
     * Disable remember token persistence since hrd_employee table has no remember_token column
     */
    public function setRememberToken($value)
    {
        // Do nothing
    }

    public function scopeActive($query)
    {
        return $query->where('active', 1);
    }

    public function department()
    {
        return $this->belongsTo(Portal\Department::class, 'orgchart_id', 'id');
    }
}
```

## 6. Service Layer

### `app/Services/Auth/VerifySession.php`

This service inspects the CodeIgniter session, checks lifetime validity, deserializes the PHP session string, and resolves the employee from HRIS.

```php
<?php

namespace App\Services\Auth;

use App\Models\Portal\CISession;
use App\Models\User;
use Illuminate\Support\Carbon;

class VerifySession
{
    /**
     * Verify CI Session and return the authenticatable User model.
     *
     * @param string $ciSession
     * @return User|false
     */
    public function checkAndGetUserByCiSession(string $ciSession): User|false
    {
        $model = CISession::where('id', $ciSession)->first();

        if (!$model) {
            return false;
        }

        // Validate session expiration
        $sessionTime = Carbon::parse((int)$model->timestamp);
        $currentTime = Carbon::now();
        $lifetime = (int) env('SESSION_LIFETIME', 120);

        $isStillValid = $sessionTime->addMinutes($lifetime)->gt($currentTime);

        if (!$isStillValid) {
            return false;
        }

        // Decode CodeIgniter serialized PHP session
        $dataCiSession = $this->parseCiSession($model);

        if (!isset($dataCiSession['uname'])) {
            return false;
        }

        $npk = $dataCiSession['uname'];

        // Retrieve Employee from HRIS database
        $userInternal = User::find($npk);

        if (!$userInternal) {
            return false;
        }

        return $userInternal;
    }

    /**
     * Decode CodeIgniter 3 session data using PHP's native session_decode.
     *
     * @param CISession $data
     * @return array
     */
    private function parseCiSession($data): array
    {
        if (!session_id()) {
            session_start();
        }

        // Prevent cross-session data contamination
        $_SESSION = [];
        session_decode($data['data'] ?? $data->data);
        $decoded = $_SESSION;

        return $decoded;
    }
}
```

## 7. Controller Layer

### `app/Http/Controllers/Web/AuthController.php`

```php
<?php

namespace App\Http\Controllers\Web;

use App\Http\Controllers\Controller;
use App\Services\Auth\VerifySession;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

class AuthController extends Controller
{
    /**
     * Handle incoming SSO login request from the portal.
     */
    public function login(Request $request): mixed
    {
        // Clear any existing local session to ensure clean state
        if (Auth::check()) {
            Auth::logout();
        }

        $ciSession = $request->query('ciSession');

        // If no session passed, redirect user to Portal to authenticate
        if (empty($ciSession)) {
            return redirect(config('app.redirect.portal'));
        }

        $verifyService = new VerifySession();
        $user = $verifyService->checkAndGetUserByCiSession($ciSession);

        if ($user) {
            Auth::login($user);
            
            // Redirect to home or intended route
            return redirect()->intended('/dashboard');
        }

        // Session not found, expired, or employee record not found
        return abort(401, 'Unauthorized SSO Session.');
    }

    /**
     * Logout and redirect to portal.
     */
    public function logout(Request $request)
    {
        Auth::logout();
        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect(config('app.redirect.portal'));
    }
}
```

## 8. Routes & Middleware Setup

### 8.1 Routes (`routes/web.php`)

```php
<?php

use App\Http\Controllers\Web\AuthController;
use Illuminate\Support\Facades\Route;

// SSO Login Entry Point
Route::get('/login', [AuthController::class, 'login'])->name('login');
Route::post('/logout', [AuthController::class, 'logout'])->name('logout');

// Protected Routes
Route::middleware(['auth'])->group(function () {
    Route::get('/dashboard', function () {
        return view('dashboard');
    })->name('dashboard');

    // For Vue / React SPA fallback (if applicable):
    Route::get('/{any?}', function () {
        return view('app');
    })->where('any', '[\/\w\.-]*');
});
```

### 8.2 Handling Unauthenticated Redirects

In Laravel 11 (`bootstrap/app.php`), configure the unauthenticated redirect target if necessary:

```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->redirectGuestsTo(fn () => route('login'));
})
```
When an unauthenticated user hits any route protected by `auth`, Laravel redirects them to `route('login')` (`/login`). Since they have no `ciSession` query parameter, `AuthController::login` automatically redirects them to the central Portal!

## 9. SPA / API Support (Sanctum)

If building an SPA (Vue, React, Inertia) consuming an internal `/api/*` backend:

1. In `bootstrap/app.php`:
   ```php
   $middleware->statefulApi();
   ```
2. In `config/sanctum.php`:
   Ensure `guard => ['web']` and stateful domains include the app's domain and localhost ports.
3. Fetch the authenticated user in your frontend via:
   ```php
   // routes/api.php
   Route::middleware('auth:sanctum')->get('/user', function (Request $request) {
       return response()->json([
           'data' => $request->user()->load('department')
       ]);
   });
   ```

## 10. Checklist for Antigravity Implementation

When starting this in the new repository:

- [ ] Check SQL Server extension is installed on PHP runtime (`php -m | grep sqlsrv`).
- [ ] Add `portal` and `USER_HRIS` database connections to `config/database.php`.
- [ ] Add `.env` keys (`DB_DATABASE_PORTAL`, `DB_DATABASE_HRIS`, `PORTAL_URL`, `SESSION_LIFETIME`).
- [ ] Create `App\Models\Portal\CISession` model.
- [ ] Create `App\Models\User` extending `Authenticatable`, mapped to `USER_HRIS.dbo.hrd_employee`.
- [ ] Create `App\Services\Auth\VerifySession` service with `checkAndGetUserByCiSession()` and `parseCiSession()`.
- [ ] Create `App\Http\Controllers\Web\AuthController` with `login()` and `logout()`.
- [ ] Register `GET /login` in `routes/web.php` named `login`.
- [ ] Protect application routes with `middleware('auth')`.
- [ ] Verify redirects work: visiting `/dashboard` unauthenticated redirects to `/login` -> redirects to Portal. Visiting `/login?ciSession={valid_id}` logs in and redirects to `/dashboard`.
